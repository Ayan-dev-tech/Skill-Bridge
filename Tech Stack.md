# Tech Stack

## Frontend

* **Next.js** — Full-stack React framework
* **TypeScript** — Type-safe development
* **Tailwind CSS** — Utility-first styling
* **shadcn/ui** — Reusable UI components

## Backend

* **Next.js API Routes** — Application APIs and business logic
* **Python + FastAPI** — AI/ML services and processing

## Database

* **PostgreSQL** — Primary relational database
* **Supabase** — Database platform and backend services
* **pgvector** — Vector storage and semantic matching

## Authentication & Storage

* **Supabase Auth** — User authentication and role-based access
* **Supabase Storage** — Resumes, certificates, and document storage
* **Row Level Security (RLS)** — Role-based data protection

## AI & Intelligence

* **Python** — AI/ML processing
* **Rule-Based Engine** — Eligibility, scoring, and deterministic matching
* **Ollama** — Local AI model execution
* **Open-Source LLMs** — AI-powered recommendations and analysis
* **Embeddings + pgvector** — Semantic skill and job matching

## Search & Matching

* **PostgreSQL Full-Text Search** — Jobs, skills, courses, and profiles
* **pgvector** — Semantic similarity and recommendation engine
* **Weighted Matching Algorithm** — Candidate-job compatibility scoring

## Document & Resume Processing

* **PDF/Text Extraction** — Resume and document processing
* **OCR** — Extract information from uploaded documents
* **ATS Analysis Engine** — Resume and job-description matching

## Deployment

* **Vercel** — Frontend and Next.js deployment
* **Supabase** — Database, authentication, and storage
* **GitHub** — Version control and collaboration

## Development

* **Git** — Version control
* **GitHub** — Repository and collaboration

### Supported Roles

The same core technology stack powers all four platform roles:

* **Student**
* **Faculty**
* **Campus**
* **Industry**
